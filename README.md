# Драконья наковальня, сборка APK

Игра лежит в `www/index.html` вместе со шрифтами и работает без интернета. Проект завернут в Capacitor, APK собирается в облаке на GitHub.

## Как получить APK (без компьютера, можно с телефона)

1. Создайте репозиторий на github.com (приватный подойдёт).
2. Загрузите в него все файлы из этого архива, включая папку `.github`. Если создаёте репозиторий через сайт, используйте «Add file → Upload files» и перетащите содержимое распакованного архива.
3. Откройте вкладку **Actions**. Сборка «Build APK» запустится сама после загрузки. Если нет, нажмите «Run workflow».
4. Через 5–10 минут откройте завершённый запуск, внизу в разделе **Artifacts** скачайте `dragon-anvil-apk`. Внутри файл `app-debug.apk`.
5. Откройте APK на телефоне и разрешите установку из этого источника.

Это debug-сборка: она подписана отладочным ключом и ставится на телефон напрямую. Для Google Play нужна release-сборка с вашим ключом.

## Как собрать на компьютере

Нужны Node 22, JDK 21 и Android Studio (или Android SDK).

```
npm install
npx cap add android
npx cap open android
```

В Android Studio выберите Build → Build APK(s).

## Что поменять

- Название приложения и идентификатор: `capacitor.config.json` (`appName`, `appId`).
- Сама игра: `www/index.html`. После правок на компьютере запустите `npx cap sync`.
- Иконка: по умолчанию стоит стандартная иконка Capacitor. Свою можно добавить через пакет `@capacitor/assets`.
